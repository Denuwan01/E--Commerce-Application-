# Simple E-Commerce Website

This is a basic e-commerce website built using **HTML, CSS, and JavaScript**. It showcases a selection of products for sale, includes a shopping cart feature, and provides a responsive design.

## Features
- 📌 Home page with product listings  
- 🛒 Add to cart functionality  
- 🎨 Responsive design  
- ✨ Simple animations for a modern look  
- 💳 Checkout button (non-functional for demo purposes)  

## Technologies Used
- **HTML** for structure  
- **CSS** for styling  
- **JavaScript** for interactivity
